# Architecture Decision Records

Los ADR registran decisiones transversales y duraderas. No sustituyen el plan de
una iniciativa SDD ni se usan para decisiones locales y reversibles.

## Estados

- `proposed`: en revisión.
- `accepted`: decisión vigente.
- `superseded`: reemplazada por otro ADR.
- `deprecated`: ya no debe aplicarse y no tiene reemplazo directo.

consecuencias y alternativas, y enlazan la iniciativa SDD que los origina.
